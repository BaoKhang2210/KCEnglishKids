Two parallel MVC slices sit under src/controllers + src/routes, each paired with a Mongoose model in src/models.

- Routes: `vocabularyRoutes.js` mounts GET `/api/vocabulary` (list with topic/ageGroup/search filters) and GET `/api/vocabulary/:id`; `vocabMasteryRoutes.js` mounts child-scoped endpoints under `/children/:childId/vocabulary-mastery` (`GET`, `POST` sync, `POST .../record`) and is wired through the shared `protect` auth middleware from `../middlewares/authMiddleware`.
- Controllers: `vocabularyController.js` exposes `getVocabularyList` / `getVocabularyById`, querying `Vocabulary` with `.populate('primaryMedia' | 'audioMedia' | 'sourceUnits' | 'topics')`. `vocabMasteryController.js` exports four handlers — `getChildMastery`, `syncMastery` (bulk upsert via `bulkWrite`), `recordPractice` (single-attempt increment), `getStudentMastery` — all enforcing that CHILD users can only access their own `_id` while TEACHER/ADMIN may view any student.
- Models: `Vocabulary` holds bilingual word entries linked to `AgeGroup`, `CurriculumUnit`, `Topic`, and `Media`; `VocabularyMastery` tracks per-student progress with a `pre('save')` hook that auto-recalculates `masteryLevel` using the exported `calculateMasteryLevel` function and `MASTERY_CONFIG` constants; `CurriculumBook` (bookNumber 1–3, unique) → `CurriculumUnit` (unique on bookNumber+unitNumber, ageGroupCode-scoped); `LanguageContent` is a polymorphic container over WORD/PHRASE/SENTENCE/etc. referencing Vocabulary, CurriculumUnit, Topic, Lesson; `Media` is the shared asset store referenced by primaryMedia/audioMedia/imageMedia fields across models.
- Dependency direction is one-way: routes → controllers → models; controllers import shared helpers (`calculateMasteryLevel`) from the model file rather than duplicating business logic.
