All five child domains (auth/admin, learning activities, vocabulary curriculum, progress tracking, classroom management) are independent Express route modules mounted by `src/app.js` onto distinct `/api/*` prefixes (`/api/auth`, `/api/topics`, `/api/lessons`, `/api/activities`, `/api/vocabulary`, `/api/learning`, `/api/children`, `/api/admin`, `/api/teacher`, `/api/teacher/classroom-sessions`). Cross-cutting concerns live outside the domain folders: `src/middlewares/authMiddleware.js` is imported by controllers that need role-based access; `src/middlewares/errorMiddleware.js` provides centralized `notFound` and `errorHandler` middlewares registered last in `app.js`; `src/config/db.js` connects to MongoDB via Mongoose and is required by each domain's model index. Domain models under `src/models/` are the only cross-child contract — routes/controllers never talk directly to the DB without going through their Mongoose model. Seed data lives in `src/seeds/` and static JSON fixtures in `data_backup/`, consumed by scripts under `scripts/` and `src/scripts/` for migration and demo population.
