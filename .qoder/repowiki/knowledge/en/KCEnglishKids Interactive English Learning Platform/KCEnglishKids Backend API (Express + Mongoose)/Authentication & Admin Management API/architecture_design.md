Two parallel route trees under `src/routes`: `authRoutes.js` exposes public auth endpoints (`/api/auth/*`) and one protected profile endpoint, while `adminRoutes.js` exposes `/api/admin/*` management endpoints. Both mount into the app via Express routers. Controllers in `src/controllers/authController.js` and `src/controllers/adminController.js` are plain async functions that read from Mongoose models imported through `../models`. Authentication is centralized in `src/middlewares/authMiddleware.js`, which provides three composable middlewares: `protect` (Bearer JWT decode + active-user lookup), `authorize(...roles)` (role gate), and `optionalProtect` (non-failing token parse). The data layer lives in `src/models/User.js` (bcrypt-hashed password/PIN with `matchPassword`/`matchPin` methods, role/status enums, age-group/class references) and `src/models/AuditLog.js` (action/target/details log written by admin mutations). Dependency direction is one-way: routes → controllers → middlewares + models; controllers never import each other.
