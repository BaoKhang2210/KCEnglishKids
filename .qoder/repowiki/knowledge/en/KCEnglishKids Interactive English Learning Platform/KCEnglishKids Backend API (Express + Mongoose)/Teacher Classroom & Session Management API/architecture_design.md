Three Express routers/controllers form the module: `classroomSessionRoutes.js` mounts a dedicated session router under `/api/teacher/classroom-sessions`, while `teacherRoutes.js` is the umbrella teacher router that also wires in `parentNotificationController` (for `/api/teacher/parent-notifications`) and `vocabMasteryController`. Both route files apply `protect` + `authorize('TEACHER','ADMIN')` middleware globally so every handler assumes an authenticated teacher/admin. Controllers are stateless request handlers that call Mongoose models from `../models` (`ClassRoom`, `Assignment`, `ParentNotification`, `TeacherNote`, plus shared `User`, `Lesson`, `Activity`, `LearningSession`, `CurriculumUnit`, etc.). The session controller owns the full session lifecycle (SCHEDULED → LIVE → COMPLETED) with per-student score rows and question-result tracking; the teacher controller handles class CRUD, student enrollment, assignment lifecycle, curriculum content lookup, and note CRUD; the notification controller builds templated text reports and persists them as `ParentNotification` records. Models used here (`ClassRoom`, `TeacherNote`, `ParentNotification`, `AgeGroup`, `Assignment`) define the persistent schema; other models are imported but defined elsewhere.
