# KCEnglishKids storybook collection — 01/11/2026

Six original AI-generated 2D storybook scenes created with OpenAI image generation for this project, using the user-approved soft 2D direction. These scenes depict fictional characters; no student photographs were used.

| Asset | Intended use |
| --- | --- |
| classroom-v1.webp | Welcoming classroom, teacher preparation and teaching goals |
| family-v1.webp | Family activities and private learning portfolio |
| adventure-v1.webp | Child learning journey, exploration and welcome |
| rest-v1.webp | Movement and voluntary pause between short activity groups |
| celebration-v1.webp | Celebrate individual effort and completion |
| studio-v1.webp | Teacher/admin learning material preparation |

Generated PNG originals are preserved in the generation archive and the workspace `.local-backups/storybook-originals`. WebP delivery versions preserve the composition at 1536×1024 and use quality 88, around 280–450 KB per scene. Scenes supplement the existing vocabulary illustrations; they are decorative contexts and are not substituted for verified answer images.
